# ChineseEcho

**Listen. Learn. Remember.**

ChineseEcho is a native macOS app for practicing Chinese dictation,
organizing vocabulary, reviewing missed words, and generating contextual
example sentences with optional on-device AI.

## Features

- **Smart Dictation** — Practice Chinese vocabulary using native macOS speech.
- **Vocabulary Library** — Organize words, meanings, pinyin, tags, and learner hints.
- **Scheduled Review** — Revisit words based on your practice results.
- **Contextual Examples** — Generate modern bilingual examples using optional Local AI.
- **Flexible Pronunciation** — Choose Mainland or Taiwanese Mandarin voices and adjust playback.
- **Local Backup** — Export and restore your learning library as a JSON backup.

## Private by design

Your vocabulary, practice history, generated content, and preferences stay
on your Mac. ChineseEcho does not include advertising, cross-app tracking,
or developer-operated analytics.

If you choose to install Local AI, ChineseEcho downloads the model from
Hugging Face. Example generation then runs locally on your Mac.

[Read the Privacy Policy](privacy/)

## Requirements

- macOS 15.6 or later
- Approximately 2.5 GB of available storage if Local AI is installed
- Internet access to download the optional Local AI model

Supported Mac architectures will be listed here before the first public release.
